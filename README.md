Welcome to my digital headquarters. This is a high-performance, SEO-optimized portfolio built with **ASP.NET Core 8.0 MVC** and **MongoDB**, designed to showcase scalable software solutions and immersive digital identities.

## 🧐 What's Inside?

*   **⚡ High Performance**: Optimized with hybrid CSS loading to eliminate FOUC and browser caching for lightning-fast repeat visits.
*   **📱 Mobile-First Precision**: Custom "Intersection Observer" logic that simulates hover effects on touch devices—swapping project images and zooming cards as you scroll.
*   **🎨 Dynamic Skill Marquees**: Dual-direction, synchronized scrolling rows creating a vibrant, high-energy tech stack showcase.
*   **🛡️ Secure Admin Panel**: A private dashboard for real-time content management (Projects, Education, Experience, and Blog) powered by MongoDB.
*   **🔍 SEO Engineered**: Dynamic meta tags, Open Graph protocol integration, and automated schema.org structured data for maximum search engine visibility.

## 🛠️ Tech Stack of Destiny

- **Backend**: ASP.NET Core 8.0 MVC (C#)
- **Database**: MongoDB (NoSQL)
- **Frontend**: Razor Views, Vanilla CSS3, GSAP (Animations)
- **Deployment**: Optimized for cloud-ready environments with specific file-system CV management.

## 🏃‍♂️ How to Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/abuhuraira-73/VS-portfolio-2026.git
   ```
2. **Environment Setup:** Ensure your `appsettings.json` is configured with your MongoDB connection string.
3. **Run with Watcher (Recommended):**
   ```bash
   dotnet watch run --project VS-portfolio-2026/VS-portfolio-2026.csproj
   ```
4. **Access the Site:** Open `http://localhost:5005` in your browser.
